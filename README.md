# Larkfield Digital — website

Static site for Larkfield Digital, a fictional B2B demand-generation agency in
Austin. Used in the marketing demo org.

- `index.html` — home: positioning, proof, selected work, how we work
- `services.html` — three retainer tiers and a comparison table
- `work.html` — six client case studies
- `faq.html` — first-call questions
- `assets/site.css` — the design system; no inline styles except the table

Type is Bricolage Grotesque over Instrument Sans, from Google Fonts. Commits to
a single light appearance so it renders the same on any presenter's machine.
